**The purpose of this Application**

This is a chatroom which uses networking and concurrency to allow multiple users to connect to a server and message each other in real-time while keeping all of the messages and content sent through the room consistent.  
  
Some of the functionality includes calls, video calls, live streaming, sending images/gifs, changing usernames, checking number of people in a chatroom, and switching chatrooms while allowing concurrent chat histories in each chatroom, allowing people to join and leave at will without missing any of the conversations. 

To run it for yourself, you must simply run the server file, and then go to the Client class and run the GUI configuration to enter a login screen, from there any username will do, and you can chat and use it as you please.
